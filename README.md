# NEXUS — truck box system

Custom home screen and AI assistant for Nathan's truck box (Android 10).

## Install on the box
Open this link in the box's web browser and install the file:

**https://github.com/nathanzehner34-lang/nexus-box/releases/latest/download/nexus.apk**

## What it does
- Startup sequence: green system check read out loud, then "Hello, Nathan. Biometrics complete. How may I assist you?"
- Flowing light-ribbon background
- Buttons: YouTube (SmartTube), Stremio, Maps, Messages, Party Mode, Trivia Night, Story Mode, Daily Briefing, Intruder Alert, Night Drive, All Apps, Settings
- Tap the green orb to talk to Nexus (Google Gemini, free tier; key goes in Settings on the box, never in this repo)

Every push to `main` builds a new `nexus.apk` automatically (GitHub Actions).
